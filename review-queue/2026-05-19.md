**Suggestions (2):**

**[S1] `useLogger` inline object causes spurious `useEffect` re-runs**
- `TicketLookupForm.tsx` lines ~35 + ~215
- `useLogger({ module: 'ticket-lookup' })` passes a new object literal every render. `useLogger` uses `useMemo(..., [logger, context])`, so it returns a new `Logger` instance every render. The PR added `logger` to `useEffect([logger, result])`, which means the effect re-fires on every render when `result` is non-null — spamming "Ticket lookup leg unavailable" log entries on every re-render after a successful lookup.
- Fix: `const loggerContext = useMemo(() => ({ module: 'ticket-lookup' } as const), [])` before the `useLogger` call.

**[S2] Missing test for `Contact Wanderu Support Clicked` with `entry_point: 'ticket_lookup_noticket'`**
- `TicketLookupForm.test.tsx`
- Two of three CS-click callsites are tested (`ticket_lookup_form`, `ticket_lookup_not_found`). The noticket help link callsite has no test asserting the new event name or `entry_point`.
- Fix: Add a test that renders a noticket-leg result, clicks the help link, and asserts `amplitude.track('Contact Wanderu Support Clicked', { entry_point: 'ticket_lookup_noticket' })`.
