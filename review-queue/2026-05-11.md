### DISPUTED (not blocking)

**D1: `...extra` spread after explicit WAPI fields — theoretical overwrite risk**
`...extra` spreads last, so `extra: { source: 'anything' }` silently replaces `source: 'ui-react'`. Current single caller is safe. Consider placing `...extra` before named fields or stripping reserved keys.

**D2: `return await` inside try inconsistent with `fireCheckoutEvent`**
Both new functions correctly use `return await wapiService.post()` to catch rejections. `fireCheckoutEvent` doesn't, making the `await` look accidental. Better fix: make `fireCheckoutEvent` consistent rather than adding a comment.
